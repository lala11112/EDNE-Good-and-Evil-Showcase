# 용기 랭크 화면 가장자리 반짝임 효과 가이드

## 📋 개요

플레이어의 용기 랭크가 올라갔을 때 화면 가장자리에 반짝거리는 효과를 표시하는 시스템입니다.
쉐이더를 사용하여 부드럽고 눈에 띄는 시각적 피드백을 제공합니다.

---

## 🎯 주요 특징

### 1. **자동 랭크 감지**
- `PlayerController`의 랭크 변경을 자동으로 감지
- 랭크가 올라갔을 때만 효과 트리거 (랭크 하락 시 효과 없음)

### 2. **쉐이더 기반 효과**
- 커스텀 쉐이더로 부드러운 반짝임 효과
- 화면 가장자리 거리 기반 그라데이션
- 시간 기반 노이즈로 자연스러운 반짝임

### 3. **랭크별 색상 설정**
- 기본 색상 또는 랭크별 색상 오버라이드 지원
- ScriptableObject로 쉬운 설정 관리

### 4. **부드러운 페이드**
- 효과 지속 시간 후 자동 페이드 아웃
- 설정 가능한 페이드 시간

---

## 🛠️ Unity 에디터에서 설정하기

### **1단계: ScriptableObject 생성**

1. **Project 창**에서 우클릭 → `Create` → `Player` → `Courage Rank Effect Data`
2. 이름을 `CourageRankEffectData`로 변경
3. **Inspector**에서 설정:
   - **Effect Duration**: 효과 지속 시간 (기본: 2초)
   - **Fade Out Duration**: 페이드 아웃 시간 (기본: 0.5초)
   - **Edge Color**: 가장자리 색상 (기본: 노란색)
   - **Edge Width**: 가장자리 너비 (기본: 0.1)
   - **Sparkle Intensity**: 반짝임 강도 (기본: 1.0)
   - **Sparkle Speed**: 반짝임 속도 (기본: 2.0)
   - **Noise Scale**: 노이즈 스케일 (기본: 5.0)

#### **랭크별 색상 설정 (선택적)**
- **Rank Color Overrides** 배열에 랭크별 색상 추가 가능
- 예: S랭크는 금색, A랭크는 은색 등

---

### **2단계: UI Canvas에 효과 오버레이 추가**

#### **2-1. Fullscreen Image 생성**

1. 기존 UI Canvas를 찾거나 새로 생성
   - `Hierarchy` → 기존 Canvas 또는 `UI` → `Canvas` 생성
   - Canvas 이름: `GameCanvas` 또는 기존 Canvas 사용

2. Canvas 하위에 **Image** 생성
   - Canvas 하위 우클릭 → `UI` → `Image`
   - 이름을 `CourageRankEdgeEffect`로 변경

3. **Rect Transform** 설정:
   - **Anchors**: 전체 화면 (Stretch-Stretch)
   - **Anchor Presets**: Alt+Shift+클릭하여 전체 화면 설정
   - **Left, Right, Top, Bottom**: 모두 `0`으로 설정

4. **Image** 컴포넌트 설정:
   - **Source Image**: 없음 (쉐이더가 색상을 생성)
   - **Color**: 흰색 (Alpha: 255)
   - **Material**: 나중에 할당 (컨트롤러가 자동 생성)

---

#### **2-2. 효과 컨트롤러 추가**

1. `CourageRankEdgeEffect` 오브젝트 선택
2. **Add Component** → `Courage Rank Edge Effect Controller` 추가
3. **Inspector** 설정:
   - **Effect Data**: 1단계에서 만든 `CourageRankEffectData` 할당
   - **Player Controller**: 자동 할당됨 (없으면 수동 할당)
   - **Ignore Initial Rank**: ✅ 체크 (게임 시작 시 초기 랭크 설정에서 효과 표시 안 함)

---

### **3단계: 완료!**

이제 설정이 완료되었습니다!
- 플레이어의 용기 랭크가 올라가면 자동으로 효과가 표시됩니다.
- 효과는 설정한 지속 시간 동안 표시된 후 부드럽게 페이드 아웃됩니다.
- **게임 시작 시 초기 랭크 설정에서는 효과가 표시되지 않습니다** (Ignore Initial Rank 옵션)

---

## 🎨 효과 커스터마이징

### **초기화 설정**

컨트롤러의 **Ignore Initial Rank** 옵션:
- ✅ **체크 (기본값)**: 게임 시작 시 초기 랭크 설정에서 효과 표시 안 함
  - 게임 시작 시 플레이어의 초기 랭크가 설정될 때는 효과가 트리거되지 않습니다
  - 실제로 랭크가 올라갈 때만 효과가 표시됩니다
- ❌ **체크 해제**: 초기 랭크 설정에서도 효과 표시
  - 게임 시작 시에도 효과가 표시됩니다 (일반적으로 권장하지 않음)

### **색상 변경**

1. `CourageRankEffectData` SO 선택
2. **Edge Color** 변경
   - 예: 금색 (255, 215, 0)
   - 예: 은색 (192, 192, 192)
   - 예: 파란색 (100, 150, 255)

### **랭크별 색상 설정**

1. `CourageRankEffectData` SO 선택
2. **Rank Color Overrides** 배열 크기 증가
3. 각 요소에 랭크와 색상 설정:
   - **Rank**: S, A, B, C, D 중 선택
   - **Color**: 해당 랭크의 색상

### **효과 강도 조절**

- **Edge Width**: 가장자리 영역 크기 (작을수록 얇은 가장자리)
- **Sparkle Intensity**: 반짝임 강도 (높을수록 밝게 반짝임)
- **Sparkle Speed**: 반짝임 속도 (높을수록 빠르게 반짝임)
- **Noise Scale**: 노이즈 패턴 크기 (높을수록 큰 패턴)

## 📝 코드 사용법

### **수동으로 효과 트리거하기**

```csharp
// CourageRankEdgeEffectController 참조 가져오기
CourageRankEdgeEffectController effectController = 
    FindObjectOfType<CourageRankEdgeEffectController>();

// 효과 트리거
if (effectController != null)
{
    effectController.TriggerEffect(SkillRank.S);
}
```

### **이벤트 기반 트리거 (선택적)**

`PlayerController`의 `OnCourageStateChanged`에서 직접 호출할 수도 있습니다:

```csharp
protected override void OnCourageStateChanged(CourageState previousState, CourageState newState)
{
    // 기존 로직...
    
    // 화면 효과 트리거
    CourageRankEdgeEffectController effectController = 
        FindObjectOfType<CourageRankEdgeEffectController>();
    if (effectController != null && IsRankUp(previousState, newState))
    {
        effectController.TriggerEffect(currentSkillRank);
    }
}
```

## 🔧 문제 해결

### **효과가 표시되지 않음**

1. **쉐이더 확인**
   - 쉐이더가 제대로 임포트되었는지 확인
   - 쉐이더 이름: `Custom/CourageRankEdgeEffect`

2. **Material 확인**
   - 컨트롤러가 Material을 자동 생성하는지 확인
   - Image 컴포넌트에 Material이 할당되었는지 확인

3. **Canvas 설정 확인**
   - Canvas의 Render Mode가 `Screen Space - Overlay`인지 확인
   - Image가 Canvas의 최상위 레이어에 있는지 확인

### **효과가 너무 강함/약함**

- `CourageRankEffectData` SO에서 다음 값 조절:
  - **Sparkle Intensity**: 반짝임 강도
  - **Edge Width**: 가장자리 영역 크기
  - **Effect Duration**: 효과 지속 시간

### **효과가 계속 표시됨**

- 컨트롤러의 `Update`에서 랭크 변경 감지가 제대로 작동하는지 확인
- `PlayerController.Instance`가 올바르게 할당되었는지 확인

## 📊 성능 고려사항

- 쉐이더는 간단한 계산만 수행하므로 성능 영향 최소
- Fullscreen Image는 한 개만 사용하므로 오버헤드 적음
- 효과는 일시적으로만 표시되므로 지속적인 성능 영향 없음
