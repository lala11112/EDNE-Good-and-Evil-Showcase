# 선악과, 편식하면 안되나요?

Unity로 만든 **2D 탑다운 액션 게임**의 공개용 코드 저장소입니다.
팀이 직접 작성한 게임 코드와 그 커밋 기록을 담았습니다.

| | |
|---|---|
| 장르 | 2D 탑다운 액션 (방 단위 진행) |
| 엔진 · 언어 | Unity · C# |
| 코드 기록 | 2025.09 – 2025.11 (커밋 156개) |

## 이 저장소에 있는 것

원본 프로젝트의 `Assets/_Project/2. Scripts` 폴더(팀이 직접 작성한 코드)를 커밋 기록과 함께 옮겨 왔습니다.

에셋스토어에서 구매한 에셋, 아트, 씬은 라이선스상 공개할 수 없어 원본 비공개 저장소에만 있습니다.
그래서 이 저장소만으로는 Unity에서 실행되지 않습니다. 코드를 읽어 보는 용도입니다.

## 주요 시스템

| 폴더 | 내용 |
|---|---|
| `Player` | 플레이어 이동, 스킬 슬롯, 대시·돌진·베기·투사체 스킬, 잔상과 열 왜곡 효과 |
| `Player` · `Core` | 용기 시스템: 용기 점수에 따라 스킬 랭크가 C → B → A → S로 오르내리고, 랭크가 오르면 화면 가장자리에 셰이더 효과가 납니다 |
| `Monster` | 몬스터 이동과 스킬 우선순위, 죽을 때 분열·폭발하는 몬스터, 화염구·충격파·산탄 스킬 |
| `Boss` | 보스 전용 방과 패턴(주변 탄막, 조준 연사, 폭탄, 직선 휩쓸기, 무작위 공격) |
| `Room` | 방 입장과 클리어, 문 열고 닫기, 몬스터 생성 |
| `Item` | 장비·소모 아이템과 아이템 효과 관리 |
| `Trap` | 가시 함정, 회전 칼날 함정 |
| `UI` | 타이틀, 일시정지, 옵션, 게임오버, 체력바·스킬바, 대화 연동 |
| `SOScript` | 플레이어·몬스터·스킬·아이템 데이터(ScriptableObject) |
| `Data` | 처치·연속 처치·스킬 사용 기록 |
