# 🚀 UI 시스템 빠른 시작 카드

## ⚡ 5분 안에 버튼 → 씬 전환 구현하기

### 1️⃣ UIManager 생성 (1분)
```
Hierarchy 우클릭
→ Create Empty
→ 이름: "UIManager"
→ Add Component → UI Manager
→ Title Scene Name: Title
→ Gameplay Scene Name: Level_01_Gameplay
```

### 2️⃣ TitleUIController 연결 (2분)
```
Canvas 선택
→ Add Component → Title UI Controller

Inspector에서 드래그:
  Game Start Button ← GameStartButton
  Option Button ← OptionButton
  Quit Game Button ← QuitGameButton
  Main Panel ← MainPanel
  Option Panel ← OptionPanel
```

### 3️⃣ Build Settings (1분)
```
File → Build Settings
→ Add Open Scenes (또는 씬 파일 드래그)

확인:
  ✓ 0. Title
  ✓ 1. Level_01_Gameplay
```

### 4️⃣ 테스트 (1분)
```
Play 버튼 (▶) 클릭
→ Game Start 버튼 클릭
→ 씬 전환 확인!
```

## 🚨 안 되면?

### 문제: 씬이 안 넘어가요
→ Build Settings 확인!
→ Scene Names 철자 확인!

### 문제: NullReference 에러
→ 버튼이 연결되었는지 확인!
→ UIManager가 씬에 있는지 확인!

### 문제: Scene couldn't be loaded
→ Build Settings에 씬 추가!
