# 버튼 ↔ 씬 이동 연결 완전 가이드

## 🎯 목표
Unity 버튼을 클릭했을 때 씬이 전환되도록 연결하기

---

## 📋 현재 구조

```
버튼 클릭 → TitleUIController → UIManager → SceneManager → 씬 전환
```

---

## 🔧 방법 1: 스크립트로 연결 (권장) ⭐

### 이미 구현되어 있음!

**TitleUIController.cs**가 이미 연결되어 있습니다:

```csharp
private void OnGameStartClicked()
{
    Debug.Log("게임 시작!");
    UIManager.Instance.LoadGameplayScene(); // ← 씬 전환!
}
```

### Unity 에디터에서 확인하는 방법

#### 1단계: Title 씬 열기
1. **Title.unity** 열기

#### 2단계: Canvas 선택
1. **Hierarchy** → **Canvas** 클릭

#### 3단계: TitleUIController 확인
1. **Inspector**에서 **Title UI Controller** 컴포넌트 찾기
2. 다음 항목들이 연결되어 있는지 확인:

```
Prefab Buttons:
  ✓ Game Start Button: GameStartButton
  ✓ Option Button: OptionButton
  ✓ Quit Game Button: QuitGameButton
  ✓ Credit Button: CreditButton
```

#### 4단계: UIManager 확인
1. **Hierarchy** → **UIManager** 선택 (없으면 추가 필요)
2. **Inspector**에서 **UI Manager** 컴포넌트 확인:

```
Scene Names:
  Title Scene Name: Title
  Gameplay Scene Name: Level_01_Gameplay
```

#### 5단계: Build Settings 확인 ⭐ 매우 중요!
1. **File** → **Build Settings**
2. **Scenes In Build**에 다음이 있는지 확인:

```
✓ 0. Title                    (Assets/_Project/1. Scenes/Demo/Title.unity)
✓ 1. Level_01_Gameplay        (Assets/_Project/1. Scenes/.../Level_01_Gameplay.unity)
```

**없으면 추가하기:**
1. **Add Open Scenes** 버튼 클릭 또는
2. Project 창에서 씬 파일을 드래그

#### 6단계: 테스트
1. **Play** 버튼 클릭 (▶)
2. **Game Start** 버튼 클릭
3. **Level_01_Gameplay** 씬으로 전환되는지 확인

---

## 🔧 방법 2: Inspector에서 직접 연결 (간단하지만 비추천)

### 장점
- 코드 수정 불필요
- 빠른 프로토타입

### 단점
- 유지보수 어려움
- 디버깅 어려움
- 확장성 낮음

### 단계별 방법

#### 1단계: 버튼 선택
1. **Hierarchy** → **Canvas** → **MainPanel** → **GameStartButton** 선택

#### 2단계: Button 컴포넌트 확인
1. **Inspector**에서 **Button** 컴포넌트 찾기
2. **On Click ()** 섹션 확인

#### 3단계: UIManager 연결
1. **On Click ()** 섹션 하단의 **+** 버튼 클릭
2. 새로 생긴 항목에서:
   - 왼쪽 빈 칸에 **Hierarchy의 UIManager** 드래그
   - 오른쪽 드롭다운: **No Function** 클릭
   - **UIManager** → **LoadGameplayScene ()** 선택

#### 4단계: 결과 확인
```
On Click ():
  ├─ Runtime Only
  ├─ UIManager (게임오브젝트 이름)
  └─ Function: UIManager.LoadGameplayScene
```

#### 5단계: 테스트
- Play → 버튼 클릭 → 씬 전환 확인

## 🎨 방법 3: 프리팹 버튼 사용 (UIButton)

### UIButton 프리팹을 사용하는 경우

이미 **TitleUIController**에서 처리하고 있습니다:

```csharp
private void InitializeButtons()
{
    // UIButton 프리팹 이벤트 연결
    if (gameStartButton != null)
        gameStartButton.OnClick.AddListener(OnGameStartClicked);
}

private void OnGameStartClicked()
{
    UIManager.Instance.LoadGameplayScene();
}
```

**추가 작업 불필요!** 이미 연결되어 있습니다.

## 🚨 문제 해결

### 문제 1: "씬이 전환되지 않아요!"

#### 원인 1: Build Settings에 씬이 없음
**해결:**
1. File → Build Settings
2. Scenes In Build에 씬 추가
3. Title이 Index 0, Gameplay가 Index 1인지 확인

#### 원인 2: 씬 이름이 다름
**해결:**
1. UIManager 선택
2. Inspector에서 Scene Names 확인:
   ```
   Title Scene Name: 실제 씬 이름과 동일해야 함!
   Gameplay Scene Name: 실제 씬 이름과 동일해야 함!
   ```

#### 원인 3: UIManager가 없음
**해결:**
1. Hierarchy에 UIManager GameObject 확인
2. 없으면:
   - Create Empty
   - 이름: "UIManager"
   - Add Component → UI Manager

#### 원인 4: 버튼이 연결 안 됨
**해결:**
1. Canvas 선택
2. TitleUIController 컴포넌트에서:
   - Game Start Button에 **GameStartButton** 드래그
   - None (UI Button)이 아닌지 확인

---

### 문제 2: "에러가 나요!"

#### 에러: "Scene 'XXX' couldn't be loaded"
**해결:**
- Build Settings에 씬 추가

#### 에러: "NullReferenceException: UIManager"
**해결:**
- UIManager GameObject가 씬에 있는지 확인

#### 에러: "The referenced script on this Behaviour is missing!"
**해결:**
- TitleUIController.cs 파일이 있는지 확인
- 스크립트 컴파일 에러 없는지 확인

---

### 문제 3: "Play 모드에서는 되는데 빌드하면 안 돼요!"

**원인:** Build Settings에 씬이 누락됨

**해결:**
1. File → Build Settings
2. 사용하는 **모든 씬**을 추가:
   - Title
   - Level_01_Gameplay
   - (기타 게임에서 사용하는 모든 씬)

---

## ✅ 체크리스트

### 씬 전환이 작동하려면:

- [ ] **UIManager** GameObject가 씬에 있음
- [ ] **UIManager**에 UI Manager 스크립트 추가됨
- [ ] **Scene Names**가 정확함 (대소문자, 공백 주의!)
- [ ] **Build Settings**에 두 씬 모두 추가됨
- [ ] **TitleUIController**가 Canvas에 있음
- [ ] **GameStartButton**이 TitleUIController에 연결됨
- [ ] **버튼 클릭** 시 Console에 "게임 시작!" 로그 출력됨

### 예제 1: 특정 레벨로 이동

#### UIManager.cs에 추가:
```csharp
/// <summary>
/// 특정 씬 로드
/// </summary>
public void LoadScene(string sceneName)
{
    SceneManager.LoadScene(sceneName);
}

/// <summary>
/// 레벨 번호로 로드
/// </summary>
public void LoadLevel(int levelNumber)
{
    SceneManager.LoadScene($"Level_{levelNumber:00}_Gameplay");
}
```

#### 사용:
```csharp
// TitleUIController.cs
void OnLevel1ButtonClicked()
{
    UIManager.Instance.LoadLevel(1);
}

void OnLevel2ButtonClicked()
{
    UIManager.Instance.LoadLevel(2);
}
```

### 예제 2: 페이드 효과와 함께 씬 전환

#### UIManager.cs에 추가:
```csharp
using System.Collections;

/// <summary>
/// 페이드 효과와 함께 씬 전환
/// </summary>
public void LoadSceneWithFade(string sceneName, float fadeTime = 1f)
{
    StartCoroutine(FadeAndLoadScene(sceneName, fadeTime));
}

private IEnumerator FadeAndLoadScene(string sceneName, float fadeTime)
{
    // 페이드 아웃
    // TODO: CanvasGroup alpha를 0으로
    
    yield return new WaitForSeconds(fadeTime);
    
    // 씬 전환
    SceneManager.LoadScene(sceneName);
}
```

#### 사용:
```csharp
void OnGameStartClicked()
{
    UIManager.Instance.LoadSceneWithFade("Level_01_Gameplay", 1f);
}
```

### 예제 3: 로딩 화면과 함께

```csharp
/// <summary>
/// 로딩 화면과 함께 씬 전환
/// </summary>
public void LoadSceneWithLoading(string sceneName)
{
    StartCoroutine(LoadSceneAsync(sceneName));
}

private IEnumerator LoadSceneAsync(string sceneName)
{
    // 로딩 씬 표시
    // TODO: 로딩 UI 활성화
    
    // 비동기 로드 시작
    AsyncOperation asyncLoad = SceneManager.LoadSceneAsync(sceneName);
    
    // 로딩 진행률 표시
    while (!asyncLoad.isDone)
    {
        float progress = asyncLoad.progress;
        // TODO: 진행률 UI 업데이트
        Debug.Log($"Loading: {progress * 100}%");
        
        yield return null;
    }
}
```

### 예제 4: 게임 데이터 저장 후 씬 전환

```csharp
void OnQuitToMainMenuClicked()
{
    // 1. 게임 데이터 저장
    SaveGameData();
    
    // 2. Time.timeScale 복구 (일시정지 상태였다면)
    Time.timeScale = 1f;
    
    // 3. 씬 전환
    UIManager.Instance.LoadTitleScene();
}

void SaveGameData()
{
    PlayerPrefs.SetInt("PlayerLevel", 5);
    PlayerPrefs.SetFloat("PlayerHP", 80f);
    PlayerPrefs.Save();
}
```

## 🎓 고급 팁

### Tip 1: 씬 전환 전 확인 팝업

```csharp
void OnQuitGameClicked()
{
    // UIPopup 사용
    quitConfirmPopup.ShowConfirm(
        "게임 종료",
        "정말 종료하시겠습니까?",
        onConfirm: () => UIManager.Instance.QuitGame(),
        onCancel: null
    );
}
```

### Tip 2: 씬 전환 전 정리 작업

```csharp
void OnGameStartClicked()
{
    // 1. 이전 데이터 정리
    CleanupPreviousData();
    
    // 2. 초기 설정
    InitializeGameSettings();
    
    // 3. 씬 전환
    UIManager.Instance.LoadGameplayScene();
}
```

### Tip 3: 씬 이름을 하드코딩하지 않기

```csharp
// ❌ 나쁜 예
SceneManager.LoadScene("Level_01_Gameplay");

// ✅ 좋은 예 (UIManager 사용)
UIManager.Instance.LoadGameplayScene();

// ✅ 또는 enum 사용
public enum SceneName
{
    Title,
    Level_01_Gameplay,
    GameOver
}

public void LoadScene(SceneName scene)
{
    SceneManager.LoadScene(scene.ToString());
}
```
