## 오늘 작업한 내용

### 1. 아이템 타입 시스템 구축
- `ItemIdentifier` enum을 `Enums.cs`에 추가
- 기존 `ItemType` (Consumable/Equipment)과 구분되는 구체적인 아이템 식별자 시스템 구축
- 아이템 타입: `Dice`, `Chain`, `Stella`, `Heartbeat`, `Other`

### 2. ScriptableObject 구조 생성
- **ItemDataSO** (베이스 클래스)
  - 기본 아이템 정보 (이름, 랭크, 설명, 아이콘 등)
  - `itemIdentifier` 필드 추가
  
- **각 아이템별 SO 클래스 생성**
  - `DiceItemDataSO`: 운명의 주사위 데이터
  - `ChainItemDataSO`: 확신의 사슬 데이터
  - `StellaItemDataSO`: 스텔라 프로토콜 데이터
  - `HeartbeatItemDataSO`: 심작박동 데이터

### 3. ItemController 싱글톤 구현
- 아이템 효과를 중앙에서 관리하는 싱글톤 컨트롤러 생성
- 아이템 등록/제거 시스템
- 아이템별 효과 데이터 관리

### 4. 효과 데이터 구조체 생성
- `DiceEffectData`: 운명의 주사위 효과
- `ChainEffectData`: 확신의 사슬 효과
- `StellaEffectData`: 스텔라 프로토콜 효과
- `HeartbeatEffectData`: 심작박동 효과

### 5. EquipmentItem 간소화
- 아이템 획득 시 `ItemController`에 등록만 수행
- 아이템 제거 로직은 나중에 다른 곳에서 처리하도록 변경

### 6. 방 진입/클리어 이벤트 연동
- `RoomController`에서 방 진입/클리어 시 `ItemController`에 알림
- 운명의 주사위 효과가 방 진입 시마다 재생성되도록 구현

## 현재 구조

### 파일 구조
```
Assets/_Project/2. Scripts/
├── Item/
│   ├── ItemBase.cs                    # 아이템 베이스 클래스
│   ├── EquipmentItem.cs               # 장비 아이템 (등록만 수행)
│   ├── ItemController.cs              # 아이템 효과 관리 싱글톤
│   ├── ItemEffectData.cs              # 아이템 효과 데이터 구조체
│   ├── DiceItemDataSO.cs              # 운명의 주사위 SO
│   ├── ChainItemDataSO.cs             # 확신의 사슬 SO
│   ├── StellaItemDataSO.cs            # 스텔라 프로토콜 SO
│   └── HeartbeatItemDataSO.cs         # 심작박동 SO
├── SOScript/ItemSO/
│   └── ItemDataSO.cs                  # 아이템 데이터 베이스 SO
├── Core/
│   └── Enums.cs                       # ItemIdentifier enum 포함
└── Room/
    └── RoomController.cs              # 방 진입/클리어 이벤트 발생
```

### 데이터 흐름

```
1. 아이템 획득
   EquipmentItem.OnItemAcquired()
   → ItemController.RegisterItem(itemData)
   → RegisterDiceItem() / RegisterChainItem() 등
   → 효과 데이터 초기화

2. 방 진입/클리어
   RoomController.EnterRoom() / ClearRoom()
   → ItemController.OnRoomEntered() / OnRoomCleared()
   → GenerateDiceEffect() (운명의 주사위만)

3. 효과 조회
   PlayerController 등에서
   → ItemController.GetDiceEffect() 등
   → 효과 데이터 반환
   → 실제 스탯에 적용
```

### 클래스 관계도

```
ItemDataSO (베이스)
    ├── DiceItemDataSO
    ├── ChainItemDataSO
    ├── StellaItemDataSO
    └── HeartbeatItemDataSO

ItemBase (베이스)
    └── EquipmentItem
        └── ItemController.RegisterItem()

ItemController (싱글톤)
    ├── RegisterItem() / UnregisterItem()
    ├── OnRoomEntered() / OnRoomCleared()
    ├── OnMonsterKilled()
    ├── OnPlayerDamaged()
    └── GetDiceEffect() / GetChainEffect() 등

RoomController
    ├── EnterRoom() → ItemController.OnRoomEntered()
    └── ClearRoom() → ItemController.OnRoomCleared()
```

## 구현된 아이템들

### 1. S랭크 운명의 주사위 (Dice)

**효과:**
- 방마다 랜덤한 효과 부여
- 공격력: -30% ~ +70%
- 이동속도: -20% ~ +30%
- 정신력회복속도: -20% ~ +20%

**동작 방식:**
- 아이템 획득 시: 첫 효과 생성
- 방 진입 시: 기존 효과 제거 후 새로운 효과 생성
- 방 클리어 시: 기존 효과 제거 후 새로운 효과 생성

**구현 상태:**
- ✅ 데이터 구조 완료
- ✅ 효과 생성 로직 완료
- ✅ 방 진입/클리어 연동 완료
- ❌ UI 표시 미구현
- ❌ 실제 스탯 적용 미구현

---

### 2. A랭크 확신의 사슬 (Chain)

**효과:**
- 몬스터 연속 처치 시 공격력 증가
- 처치당 공격력 +10% (최대 5스택)
- 연속 처치 시간 초과 시 스택 초기화

**동작 방식:**
- 몬스터 처치 시: 스택 증가, 타이머 리셋
- 연속 처치 시간 초과: 스택 초기화
- 최대 스택: 5

**구현 상태:**
- ✅ 데이터 구조 완료
- ✅ 스택 관리 로직 완료
- ✅ 타이머 관리 완료
- ❌ 몬스터 처치 이벤트 연동 미구현
- ❌ UI 표시 미구현
- ❌ 실제 스탯 적용 미구현

### 3. B랭크 스텔라 프로토콜 (Stella)

**효과:**
- 공격력 +100%
- 받는 피해 +100%
- 피격 시 아이템 파괴 및 효과 제거

**동작 방식:**
- 아이템 획득 시: 효과 활성화
- 피격 시: 아이템 파괴, 효과 제거

**구현 상태:**
- ✅ 데이터 구조 완료
- ✅ 피격 시 파괴 로직 완료
- ❌ 플레이어 피격 이벤트 연동 미구현
- ❌ 실제 스탯 적용 미구현

---

### 4. C랭크 심작박동 (Heartbeat)

**효과:**
- 기본 피해 -10%
- 연속 처치 3회 성공 시 다음 공격 데미지 +150%

**동작 방식:**
- 연속 처치 카운트 증가
- 3회 달성 시: 다음 공격 보너스 활성화
- 공격 시: 보너스 적용 후 플래그 리셋

**구현 상태:**
- ✅ 데이터 구조 완료
- ✅ 연속 처치 카운트 로직 완료
- ✅ 다음 공격 보너스 로직 완료
- ❌ 몬스터 처치 이벤트 연동 미구현
- ❌ 공격 시 보너스 적용 미구현

## 참고사항

### 현재 구조의 장점
1. **관심사 분리**: 아이템 획득은 `EquipmentItem`, 효과 관리는 `ItemController`
2. **확장성**: 새로운 아이템 추가 시 SO 클래스만 추가하면 됨
3. **중앙 관리**: 모든 아이템 효과를 `ItemController`에서 관리
4. **이벤트 기반**: 방 진입/클리어, 몬스터 처치 등 이벤트로 자동 처리

### 주의사항
1. **아이템 제거**: 현재는 등록만 하고 제거는 미구현
2. **이벤트 연동**: 몬스터 처치, 플레이어 피격 이벤트 연동 필요
3. **실제 적용**: 효과 데이터는 생성되지만 실제 스탯에 적용되지 않음
4. **UI 표시**: 효과가 적용되어도 플레이어가 확인할 수 없음
